# 00 · 快速上手

> 写给**刚接手、什么都不知道**的 AI 代理。读完这一篇就能开始干活了。

## 这是什么

**岁忆**（包名 `com.suiya.suiya`）—— 纯本地、隐私优先的 Android 应用，
用文字和图片记录「岁时节日里值得纪念的事」。

核心场景：母亲生日（公历 3/20 每年重复）→ 打开 App 看到「还有 45 天」→
提前收到本地通知 → 那天写下今年发生的事、配上照片 → 之后在时间轴上回看。

**没有服务器、没有账号、没有一个网络请求。** 所有数据在手机本地 SQLite 里，
备份靠导出 AES-GCM 加密的 JSON 文件。

## 5 分钟跑起来

```bat
:: 1. 确认工具链
D:\flutter_sdk\flutter\bin\flutter.bat --version

:: 2. 装依赖
cd /d D:\suiya_build\suiya
set PUB_CACHE=D:/suiya_build/pub-cache
set PUB_HOSTED_URL=https://pub.flutter-io.cn
set FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
D:\flutter_sdk\flutter\bin\flutter.bat pub get

:: 3. 静态分析（要求 0 error）
D:\flutter_sdk\flutter\bin\cache\dart-sdk\bin\dart.EXE analyze lib

:: 4. 单元测试
D:\flutter_sdk\flutter\bin\flutter.bat test

:: 5. 构建
D:\flutter_sdk\flutter\bin\flutter.bat build apk --release
:: 产物：build\app\outputs\flutter-apk\app-release.apk
```

装到真机：

```bat
C:\Users\XX\.workbuddy\binaries\android-sdk\platform-tools\adb.exe install -r build\app\outputs\flutter-apk\app-release.apk
```

> **注意**：如果 `dart analyze` 报 `CreateFile failed 231`（所有管道实例都在使用中），
> 那不是代码问题，是 Windows 系统级管道句柄耗尽。解法见 `07-故障排查.md`。

## 立刻要知道的 5 个坑

1. 路由只能用 `context.go()` / `context.push()`，用 `Navigator.pushNamed` 会**静默失效**
2. 算节日日期必须走 `resolveDateIn()`，不能直接 `asFestival().dateIn(year)`
3. 自定义节日 id 必须在 `main()` 里 `SuiyaStorage.registerKnownIds()` 注册
4. 改数据库必须走 `schema.dart` 的 `migrate()`，且 `version` +1
5. **每次打包前必须先升版本号**，三处同步改
