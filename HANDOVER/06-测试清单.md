# 06 · 真机测试清单

> 用户明确要求：**必须真机验证，不能只做静态检查。**
> 下面每项都标了「怎么算通过」，逐条打勾。

## 环境准备

```bat
:: 1. 装包
C:\Users\XX\.workbuddy\binaries\android-sdk\platform-tools\adb.exe install -r build\app\outputs\flutter-apk\app-release.apk

:: 2. 看日志（复现问题必开）
C:\Users\XX\.workbuddy\binaries\android-sdk\platform-tools\adb.exe logcat -c
C:\Users\XX\.workbuddy\binaries\android-sdk\platform-tools\adb.exe logcat -s flutter:* ActivityManager:E AndroidRuntime:E

:: 3. 触发重启（测冷启动持久化）
adb shell am force-stop com.suiya.suiya
adb shell am start -n com.suiya.suiya/.MainActivity
```

App 内的日志也能看：设置 → 日志，支持按 info / warning / error 过滤。
