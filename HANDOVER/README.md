## 三十秒了解状况

**岁忆** 是一个纯本地、隐私优先的 Flutter Android 应用：用文字和图片记录「岁时节日里值得纪念的事」。
内置 46 个传统节日 + 24 节气 + 用户自定义日子（生日/纪念日），提供时间轴、年度回望、本地提醒、
地点标记与照片、加密备份。**无账号、无服务端、无遥测**；v1.5.0 起有可选的 WebDAV 云备份，
数据直连用户自己配置的网盘，不经过任何岁忆自有服务器。

- 工程路径：`D:\suiya_build\suiya`
- 技术栈：Flutter 3.47.6 / Dart 3.13.5 / Riverpod 2.5 / go_router 14 / sqflite 2
- 规模：41 个 dart 文件，约 9000 行
- 当前版本：**1.5.1+13**（release APK 已构建，待真机回归，见 `06-测试清单.md`）

## 五个最容易踩的坑

1. 路由只能用 `context.go()` / `context.push()`，`Navigator.pushNamed` **静默失效**
2. 算节日日期必须走 `resolveDateIn()`，直接 `asFestival().dateIn(year)` 会让「仅此一次」每年都出现
3. 自定义节日 id 必须在 `main()` 里 `SuiyaStorage.registerKnownIds()` 注册，否则**冷启动丢数据**
4. 改数据库必须走 `schema.dart` 的 `migrate()` 且 `version` +1，迁移分支**只能往前加**
5. **每次打包前先升版本号**，三处同步改
